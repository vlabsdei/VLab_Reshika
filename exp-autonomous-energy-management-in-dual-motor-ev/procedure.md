# PROCEDURE
### Phase 1: Baseline Testing
1. Initialize the simulation page (ensuring it is set to **Phase 1: Simulation** via the top-right toggle header).
2. Set the **Surface Friction Condition** drop-down menu to `Dry Asphalt (μ = 1.0)`.
3. Ensure **Autonomous Torque Allocation** is toggled **ON** (default state). Observe how the system locks out manual sliders and maintains an optimal dynamic power split.
4. Toggle **Autonomous Torque Allocation** to **OFF** to switch the environment to Manual Mode.
5. Manually vary the **Front Motor (P1) Target** and **Rear Motor (P2) Target** sliders across their operating spectrum ($10 \text{ kW} - 150 \text{ kW}$). Record changes in system energy efficiency.

### Phase 2: Simulating Changing Dynamic Loads (Drag & Drop)
1. Keep the friction condition at `μ = 1.0` and remain in **Manual Mode**.
2. Locate the **Loads Shelf** in the upper right quadrant of the viewport canvas.
3. Left-click and drag the `Driver (80 kg)` block and drop it directly over the highlighted rear `cargo-hold` drop-zone outline on the EV chassis model. 
4. Successively drag and drop the `Passengers (150 kg)`, `Suitcase (30 kg)`, and `Crate (240 kg)` objects into the cargo spaces.
5. Note how the **Total Vehicle Mass** element increments sequentially from its base $1500 \text{ kg}$ state up to $2000 \text{ kg}$.
6. *To remove a weight at any time:* Simply hover your mouse over the block inside the trunk space (the text changes to "REMOVE") and single-click it to snap it back onto the shelf.

### Phase 3: Friction Degradation Testing (Wet & Icy Surfaces)
1. Clear all cargo elements out of the vehicle trunk back onto the shelf.
2. Select `Wet Asphalt (μ = 0.6)` from the dropdown. Set the manual sliders to $P_1 = 100 \text{ kW}$ and $P_2 = 100 \text{ kW}$. Watch for axle slippage alerts.
3. Transition the dropdown to `Ice Road (μ = 0.2)`. 
4. Observe the instantaneous real-time wheel slip triggering reactions under the same $100 \text{ kW}$ parameters.

### Phase 4: Mathematical Proof Validation
1. Click the top-right header toggle button labeled **Phase 2: Physics Proof**.
2. Review the live matrix table updating columns for dynamic mass changes, structural calculated grip limits, and the absolute verification statement text generated by the powertrain control block.

## 2. Observation Guide and Analytical Inferences

### Data Observation Matrix
When running the simulation steps, meticulously focus on the following graphical and text interfaces:

| Interface Element | Location | What it Monitors | Physical Inference |
| :--- | :--- | :--- | :--- |
| **Telemetry Vector Arrows** | Centered on individual wheels (Canvas) | **Green Arrow:** Applied Motor Power.<br>**Grey/Red Arrow:** Friction Force limit. | If the green arrow extends past the grey arrow, the color flips to red, indicating the tire's grip threshold has been breached. |
| **Wheel Slip Flashing Alerts** | Tire tread bounds on Chassis model | Visual spinning animation state accompanied by a `SLIP` tag text layer. | Indicates localized mechanical wheel-spin due to sub-optimal power matching. |
| **System Energy Efficiency Badge** | Right Side Panel | Cumulative energy optimization percentage value ($10\% - 95\%$). | Slipping a single axle instantly strikes a $-20\%$ penalty; slipping both axles commands a severe structural penalty dropping efficiency to minimum parameters. |
| **Status Performance Banner** | Right Side Panel Below Efficiency | Text blocks altering colors between Green (Optimal), Yellow (Warning), and Red (Critical). | Diagnoses vehicle stability health. Green indicates stable movement; Red signals compromised safety due to structural slip. |

### Interpretation of Calculated Outcomes
* **Autonomous Mode Mechanics:** When **Autonomous Mode** is activated, you will notice that despite adjusting target inputs to extreme parameters, the system clips values directly below the dynamically calculated `$P_{\text{limit}}$` line. If one axle saturates, the software routes remaining headroom onto the opposite motor.
* **Weight Transfer Influence:** While accelerating hard in Manual Mode, you will infer that the **Front Axle Grip Limit ($P_{\text{limit, f}}$)** drops consistently below the **Rear Axle Grip Limit ($P_{\text{limit, r}}$)**. This visually proves that longitudinal weight transfer reduces normal force on front wheels, making the front axle highly vulnerable to power slips under acceleration.
