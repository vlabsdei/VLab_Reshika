High-Voltage Charging Port Vulnerability

Modern EVs utilize communication protocols like ISO 15118 or DIN 70121 over Power Line Communication (PLC) to negotiate charging parameters with the station (EVSE).

Because the Charging Port (CP) connects directly to the internal powertrain networks (via the OBC and PDU), a compromised supply station can bypass external physical barriers and inject malicious CAN frames (e.g. spoofed commands or DoS floods). This compromises the vehicle's network integrity without physical access.
